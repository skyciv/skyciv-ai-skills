## Batch Run Results Customization 

The following options can be used to customize batch run results:

| Result Key      | Description                                      |
| ---------------- | ------------------------------------------------ |
| `batch_symbol`   | Updates the heading in the batch results column  |
| `batch_info`     | Updates the infotip in the batch results column  |
