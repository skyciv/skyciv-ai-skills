The calculate.js file is where all the action happens. The calculate file uses [javascript](https://www.javascript.com/). This is where you write the logic that performs the necessary transformations on your input to create your desired output. The calculate.js file must always return an output object based on the format specified below. The calculate.js file also handles all reporting functions, and returns the report that is generated by your calculator.

## Layout

```js
module.exports = function (input_json) {

    // Get Input
    let { a, b } = input_json;
  
    // Perform Logic

    // Per Output Format 
    let output = {};

    // Return Output
    return output;

}
```

### Output Variable Options

Each output variable can have the following keys: 

| Key          | Description                               |
|--------------|-------------------------------------------|
| label        | The label for the result                  |
| results_label| Overrides the label for the result panel. |
| value        | The value of the result                   |
| units        | The units of the result                   |
| info         | Tooltip added to the result               |
| hidden       | If ``true`` hide the result               |
| paid_only    | Make result only available to paid users  |
| standout     | Make the result standout in larger font!  |
| note         | Optional note about the result. 		   |
| hide_in_s3d  | Hide the result in the S3D output table.  |
| round        | Specify the rounding to appear in results.|
| integer      | Output is an integer (no rounding).       |

### Output Settings

The settings key is used to control certain elements of the output results. 

| Key           | Description                             |
|---------------|-----------------------------------------|
| note_style    | Either `icon` or `below`.               |
| show_log	    | Show the log icon.		              |
| show_feedback | Show the feedback icon.             	  |

### Special Result Types

By using the following strings as the ``units`` value, special results types can be created.

| Key             | Description                             					|
|-----------------|-------------------------------------------------------------|
| utility         | Display result as PASS/FAIL                 				|
| utility_status  | Display result with adjacent PASS/FAIL      				|
| utility_boolean | Display result box with PASS (value = 1) & FAIL (value = 0) |
| heading         | Heading Object                        						|
| error           | Error Object                            					|
| price           | Price object with $ symbol              					|
| price_euro      | Price object with € symbol              					|

**Utility Color Rules**

All utility boxes work with the following rules:

- `< 0.95 = PASS (GREEN)`
- `>= 0.95 < 1 >= WARN (ORANGE)`
- `>= 1 = FAIL (Red)`

Utility Booleans do not have a warn option.

### Pretty Print Package

Option for ability to print numbers nicely

#### `PrettyPrint.pretty_print.print()`

##### Set Precision while Printing

```js
PrettyPrint.pretty_print.print(3.92314); => '3.923'
PrettyPrint.pretty_print.print(3.92314, {
    "precision": 1,
}); => '3.9'
```

##### With Trailing Zeros

```js
PrettyPrint.pretty_print.print(3.9, {
    "precision": 5,
    "trailing_zeros": true
}); => '3.90000'
```

##### Define digits after exponent

```js
PrettyPrint.pretty_print.print(3923140000, {
	"digits_after_decimal": 5,
	"method": "exponential"
}); => '3.92314e9'
```

##### Using engineering notation (only multiples of 3 are used in exponents)

```js
PrettyPrint.pretty_print.print(50000, {
	"digits_after_decimal": 2,
	"method": "engineering"
}) => '50.00e3';
```

##### Using engineering notation (with significant digits instead of digits after decimal)

```js
PrettyPrint.pretty_print.print(10499000, {
	"significant_digits": 4,
	"method": "engineering"
}) => '10.40e6';
```

#### `PrettyPrint.pretty_print.prettyResults()`

Formats numbers with a specified number of significant figures, automatically switching to engineering notation for very large or very small values. Handles string-to-number coercion and snaps tiny values to zero.

##### Basic Usage with Units

```js
PrettyPrint.pretty_print.prettyResults(1234.56); => '1235'
PrettyPrint.pretty_print.prettyResults(1234.56, "kN"); => '1235 kN'
PrettyPrint.pretty_print.prettyResults(0.00456, "mm"); => '0.00456 mm'
```

##### Controlling Significant Figures

```js
PrettyPrint.pretty_print.prettyResults(3.92314, "", 3); => '3.92'
PrettyPrint.pretty_print.prettyResults(125000, "", 2); => '1.3e5'
PrettyPrint.pretty_print.prettyResults(0.0001234, "", 3); => '1.23e-4'
```

##### Engineering Notation for Large and Small Values

```js
// Large values automatically use engineering notation
PrettyPrint.pretty_print.prettyResults(1234567, "Pa", 4); => '1.235e6 Pa'

// Small values automatically use engineering notation
PrettyPrint.pretty_print.prettyResults(0.000456, "m", 4); => '4.56e-4 m'
```

##### String to Number Coercion

```js
PrettyPrint.pretty_print.prettyResults("123.456"); => '123.5'
PrettyPrint.pretty_print.prettyResults("0.0045", "mm", 2); => '0.0045 mm'
```

##### Custom Epsilon (Snap Tiny Values to Zero)

```js
// Default: values smaller than 1e-5 snap to zero
PrettyPrint.pretty_print.prettyResults(1e-6); => '0'

// Custom epsilon threshold
PrettyPrint.pretty_print.prettyResults(0.001, "m", 4, 0.0001); => '0.001 m'
PrettyPrint.pretty_print.prettyResults(0.00005, "m", 4, 0.0001); => '0 m'
```

#### `PrettyPrint.pretty_print.numberWithCommas()`

Formats numbers with comma separators for improved readability.

```js
PrettyPrint.pretty_print.numberWithCommas(1234567); => '1,234,567'
PrettyPrint.pretty_print.numberWithCommas(1234.56); => '1,234.56'
```

```js
var output = {
    'report': REPORT,
    's3d_model': s3d_model,
    'results': results_obj
};
```

## Warnings

Quick Design has an inbuilt `warn` function to help you add warnings to the calculate.js and notify user of potential issues they should be aware of. 

To call the `warn` function follow the example below:

```js
// Warn the user and add a warning block to the calculation report.
warn("My warning", true);

// Warn the user and add a warning block to the calculation report with a reference.
warn("My warning", true, "Some reference");

// Warn the user but DO NOT add a warning block to the calculation report.
warn("My warning", false);
```

## Handling Errors

Use the below code to handle errors:

```js
return ERROR(err_msg)
return ERROR(err_msg, error_title)
```

:::caution
Do not use `throw new Error`
:::

## State Management

The state management helper allows you to access the `state` object from any context or util.

```js

// calculate.js
state.my_var = "abc";
state.my_fun = foo() => { return "bar"; }

// some_util.js
logger(state.my_fun()) // "bar";
state.my_var = "123";

// other_utils.js
logger(state.my_var) // "123";

```


## FULL EXAMPLE

```js
module.exports = function (input_json) {

    ReportHelpers.printInputSummary();

    ReportHelpers.heading("Hypotenuse Calculation", 2);
    ReportHelpers.print("By Pythagoras Theorem");

    let a_squared = Math.pow(a, 2);
    let b_squared = Math.pow(b, 2);

    let c = Math.sqrt(( a_squared + b_squared )).toFixed(2);

    REPORT.block.new();
        REPORT.block.addCalculation('[math] C^2 = A^2 + B^2    \\therefore C = \\sqrt{ A^2 + B^2 } [math]');
        REPORT.block.addCalculation('[math] C  = \\sqrt{ ' + a + '^2 + ' + b + '^2 } [math]');
        REPORT.block.addCalculation('[math] C  = \\sqrt{ ' + (a_squared + b_squared) + ' } = ' + (c) + '[math]');
    REPORT.block.finish();

    var output = {
        "pass": true,
        "report": REPORT,
        "results": {
            "Missing Side (C)": {
                "value": c,
                "units": "m",
            },
        }
    }

    return output;

}
```
